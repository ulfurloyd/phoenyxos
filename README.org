#+title: phoenyxos

My NixOS configuration, built with flakes, flake-parts and a modular structure.

It manages my systems and their system/home configurations.

* hosts
- nyx: desktop
- hermes: laptop

* structure
- ~doom/~: Literate Doom Emacs configuration
- ~modules/features/~: Feature modules organized by domain: desktop, development,
  gaming, media, networking, shell, virtualization
- ~modules/hosts/~: Host entry points, hardware configuration, and host-specific settings
- ~modules/profiles/~: Shared system and Home Manager profiles
- ~modules/system/~: System-level configuration and integrations

Host configurations compose shared profiles with host-specific modules.

* deployment
The flake is the source of truth for my systems. ~Comin~ monitors this repository
and automatically reconciles deployed configurations.

Changes are tested locally with ~nh os test~, then committed and pushed to main for deployment.
